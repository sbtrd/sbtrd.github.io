# Conduct’Home v1.85

Version nettoyée de l’application de pilotage chantier Maisons ARLOGIS.

## Développement

```bash
npm install
npm run dev
```

## Construction

```bash
npm run build
```

Le dossier généré par Vite est `dist/`.

## Déploiement GitHub Pages

Pour le déploiement sans compilation, utiliser le ZIP GitHub fourni séparément. Supprimer d’abord les anciens fichiers du dépôt, puis déposer uniquement le contenu du ZIP à la racine.

## Ressources conservées

- `public/logo-arlogis.png` : logo affiché dans l’application.
- `public/app-icon.png` : icône blanche du raccourci iPhone/PWA.
