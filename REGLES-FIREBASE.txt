RÈGLES FIRESTORE POUR LA SYNCHRONISATION CONDUCT'HOME

Dans Firebase Console :
1. Ouvrir Firestore Database.
2. Ouvrir l'onglet Règles.
3. Remplacer les règles par le contenu ci-dessous.
4. Cliquer sur Publier.

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }

    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Ces règles permettent uniquement à un utilisateur connecté d'accéder à ses propres données.
